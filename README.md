# Одно касание

Головоломка для Android: выбери направление, один запуск, шарик отражается от стен и препятствий и должен пройти через все точки.

## Как устроено
- `js/engine.js` — физика отражений и проверка сбора точек.
- `js/levels.js` — генерация 20 уровней. Каждый уровень строится вокруг секретного угла, поэтому всегда решаем. Окно допуска по углу проверяется при генерации.
- `js/main.js` — экраны, управление, звук, прогресс (localStorage).
- `js/ads.js` — реклама. В браузере показывает заглушку. На телефоне использует плагин `OneTouchAds` (`showRewarded`, `showInterstitial`), когда он подключён.
- Темы оформления меняются каждые 5 уровней.

## Запуск и проверка
```
python3 -m http.server 8080      # открыть http://localhost:8080
node tools/check-levels.mjs      # проверка, что все уровни решаются
```

## Сборка APK (как в «Авторитете»)
```
npm install
npm run prepare-web              # копирует в www только игру, без ключей
npx cap add android              # один раз
npx cap sync android
```
Ключ подписи (.jks) в репозиторий и в www не кладём.
