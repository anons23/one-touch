# Одно касание

Неоновая головоломка для Android, RuStore и Яндекс Игр: прицелься, один выстрел, луч отскакивает от стен и блоков и должен пройти через все точки.

## Как устроено
- `js/engine.js` — физика луча: отскоки от стен и блоков, порталы (переносят луч), стекло (разбивается с одного удара). Каждая точка пути несёт событие для эффектов и звука.
- `js/levels-data.js` — 60 готовых уровней, `js/daily-data.js` — 365 уровней дня. Создаются `tools/generate-levels.mjs` (с флагом `--daily` — уровни дня). Каждый уровень строится от секретного угла, поэтому всегда решаем; при генерации проверяется допуск по углу.
- `js/levels.js` — загрузка уровней и палитры 4 зон.
- `js/main.js` — экраны, отрисовка, полёт, меню с живым фоном, уровень дня, подсказки, реклама.
- `js/audio.js` — весь звук кодом (Web Audio), синтвейв: у каждой зоны свой ритм и лад.
- `js/platform.js` — сам определяет Яндекс Игры / Android / браузер: реклама, сохранения (на Яндексе ещё и в облако), Game Ready и разметка геймплея.
- `js/ads.js` — реклама для Android (плагин `OneTouchAds`) и заглушка в браузере.
- `js/i18n.js` — русский и английский, язык выбирается автоматически.
- `js/analytics.js`, `js/config.js` — Яндекс Метрика (номер счётчика в `METRIKA_ID`, 0 = выключено, события копятся локально, смотреть с `?stats=1`).

## Рост сложности
- Зоны по 15 уровней: Неон, Океан, Закат, Космос.
- 1–5: прицел показывает 2 отскока наперёд, 6–12: один, дальше без подсказки.
- Точек от 3 до 7, блоков до 5, лимит отскоков от 4 до 10.
- С 21-го уровня порталы, с 41-го стекло.
- Допуск по углу: от 5° в начале до 1,8° в конце. Кнопки ◀ ▶ (можно зажать) двигают прицел на 0,3°.

## Уровень дня
- Новый уровень каждый день (с порталами через день и стеклом раз в три дня).
- За первое прохождение: +1 бесплатная подсказка (до 5) и серия дней подряд, пропуск дня сбрасывает серию.

## Аналитика
Цели в Метрике («JavaScript-событие»): `game_open`, `level_start`, `level_win`, `level_quit`, `hint`, `daily_start`, `daily_win`, `daily_quit`, `ad_rewarded`, `ad_interstitial`. Параметры посетителя: `max_level`, `daily_streak`.

## Реклама
- За награду: подсказка (сначала тратятся бесплатные).
- Полноэкранная: каждый 3-й пройденный уровень, сразу после победы, до окна с кнопками.

## Перед релизом
- В `js/main.js` поставить `TEST_UNLOCK_ALL = false` (сейчас для теста открыты все уровни).

## Запуск и проверка
```
python3 -m http.server 8080              # открыть http://localhost:8080
node tools/generate-levels.mjs           # пересоздать 60 уровней (~5 с)
node tools/generate-levels.mjs --daily   # пересоздать уровни дня (~1 мин)
node tools/check-levels.mjs              # проверка всех уровней
```

## Сборка APK
```
npm install
npm run prepare-web              # копирует в www только игру, без ключей
npx cap add android              # один раз
npx cap sync android
```
Ключ подписи (.jks) в репозиторий и в www не кладём.
